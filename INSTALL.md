# Set up a Timber site

**→ [Open the setup guide](https://timaidley.github.io/Timber/install.html)**

Setting up a site means choosing between three git hosts, four sign-in methods and two deploy
targets, and most of the instructions only apply to some of those combinations. Rather than ask
you to read past the parts that don't, the guide is an interactive page: pick where your source
lives, how you want to sign in and where the site is served from, and it shows only the steps
you need — with your account and repo name filled into every URL, callback and setting, and a
tick box beside each step so you can keep your place.

That page is the **canonical** setup documentation. It lives at
[`docs/install.html`](docs/install.html) in this repo — a single dependency-free file, so you
can also just download it and open it locally.

> With JavaScript off it shows every path in order, each labelled with the combination it
> applies to.

Want to run the editor on your own machine, build a site by hand, or hack on Timber itself? See
**[`DEVELOPMENT.md`](DEVELOPMENT.md)** instead.
